Privacy Policy

It Multiplies Poster. Last updated November 10, 2026.

It Multiplies Poster is a private tool used only by the owner of the It Multiplies channel. It is not offered to the public, and no other person's account is connected to it.

What the tool accesses

Using the YouTube API Services, the tool uploads videos to the owner's own YouTube channel and reads those videos' statistics and analytics. Using Meta's Instagram APIs, it publishes videos to the owner's own Instagram account and reads their insights.

How data is stored

Login tokens, upload records and statistics are stored only on the owner's own computer. The tool has no server or database.

How data is shared

The tool does not sell or share data with anyone. Data is sent only to YouTube and Instagram in order to perform the actions above.

Third-party services

This tool uses YouTube API Services. By using it, you are subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be withdrawn at any time from the Google account permissions page. Deleting the tool's local files removes all stored data.
